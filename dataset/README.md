# Student Performance AI Dataset

This folder contains fictional data for the Explainable Student Performance AI college mini-project.

- `student_performance.csv`: one current academic snapshot per student.
- `weekly_behavior.csv`: six timestamped-style weekly observations per student.

The records are synthetic and contain no real student information. They are intended for demonstration, learning, and testing only. They should not be used to make authoritative academic decisions.

## Columns

`student_performance.csv` includes attendance, assignment score, quiz score, exam score, learning activity, submission consistency, and a demo performance category.

`weekly_behavior.csv` includes weekly attendance, assignment, quiz, and learning activity values for trend charts.
